# Files And Folders

`main.py` - короткий стартовый файл. Его запускают из RhinoCode; он находит корень проекта и передает управление в `cam/job.py`.

`Geometry to layers.py` - подготовительный скрипт для Rhino. Он раскладывает исходные кривые по слоям `List_1`, `List_2`, `List_3` и создает направляющие прямоугольники.

`cam/` - вся логика RhinoCAM-обработки.

`cam/job.py` - основной сценарий: находит кривые, создает `Setup`, добавляет операции и делает один G-code файл на каждый лист.

`cam/classification.py` - определяет тип кривых по размеру: наколка, сквозные отверстия, выборки и внешний контур.

`cam/config.py` - размеры, глубины обработки и пути к выходным файлам.

`cam/operations.py` - низкоуровневая настройка RhinoCAM MOp: глубина, сторона реза, подачи, регенерация траектории.

`cam/tools/` - JSON-файлы с параметрами инструментов, сейчас используется `tool_D3.json`.

`core/` - общие служебные функции, не привязанные напрямую к RhinoCAM-операциям.

`core/project.py` - поиск корня проекта, особенно важен при запуске из временной папки RhinoCode.

`core/layers.py` - фильтрация и порядок слоев `List_*`.

`core/files.py` - поиск созданного G-code файла и переименование в имя setup.

`core/logging_utils.py` - вывод сообщений в терминал RhinoCode и запись в `rhinocam_main.log`.

`geometry/` - функции для работы с Rhino-геометрией.

`geometry/curves.py` - поиск кривых, bounding box и краткое описание кривой.

`plugins/` - тонкие обертки над внешними API.

`plugins/rhino8.py` - операции Rhino: выбор объектов, слой объекта, безопасное имя файла.

`plugins/rhinocam.py` - операции RhinoCAM API: инициализация, инструмент, stock, setup, post-process.

`data/` - исходные данные проекта.

`data/models/` - Rhino-модели `.3dm`.

`GCode/` - результат работы скрипта: готовые `.nc` файлы. Папку можно очищать перед новым тестом.

`examples/` - примеры ранее полученных УП для сравнения.

`archive/` - старые пробные версии скриптов, оставлены как история и запасной материал.

`tools/` - вспомогательные скрипты для разработки, не основной запуск RhinoCAM.

`docs/` - дополнительная документация по проекту.

`__pycache__/` - служебный кэш Python. Его можно не трогать; он не нужен для понимания проекта.

`.gitignore` - список файлов и папок, которые не нужно хранить в git: кэш, логи, сгенерированные УП.

`rhinocam_main.log` - лог последнего запуска `main.py`.

`~$README.md` - временный файл блокировки редактора/Office/синхронизации. Это не часть проекта, его можно игнорировать.
